# Traffic Volume Prediction

## Overview
This project uses machine learning to predict traffic volume using traffic and environmental data. It compares Linear Regression and Random Forest models to evaluate prediction performance.

## Objectives
- Clean and prepare traffic data.
- Explore data and identify useful features.
- Train regression models.
- Evaluate models using MAE, RMSE, and R².
- Save the best-performing model.

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- **MAE:** Mean Absolute Error.
- **RMSE:** Root Mean Squared Error.
- **R² Score:** Measures how well the model explains variation in traffic volume.

Actual scores will be added after checking the notebook's evaluation output.
